# ⚡ RasgaPDF Spatial Viewer

Interactive 2D Spatial PDF Layout & Geometry visualizer powered by **RasgaPDF** (Rust native core).

## Features
- **Physical 2D Bounding Boxes:** Text blocks, lines, and word spans.
- **Spatial Table Detection:** Zero-loss table matrices with structured rows and columns.
- **Polyglot Bindings:** Python, Node.js, Go, and C# (.NET).
- **Sub-millisecond Latencies:** Multi-threaded parallel processing using `rayon`.

Visit the GitHub Repository: [https://github.com/messiasmartins/rasgapdf](https://github.com/messiasmartins/rasgapdf)
